# 轻课表 · CUPK

**专门用于中国石油大学（北京）克拉玛依校区的 Android 课表 App。**

面向本校区学生，适配 [校区教务系统](https://eams.cupk.edu.cn/student/home)。支持在校方页面登录后导入个人课表，并在手机上查看课程、周次、教室与待办。

个人独立开发，非学校官方应用。当前仅提供该校区的教务导入适配，其他学校暂不支持。

- 已安装旧版时可直接覆盖安装，无需卸载。卸载前请先导出 JSON 备份。

## 主要功能

- 教务系统导入：电脑模式、页面缩放、固定读取按钮、导入预览与待核对清单。
- 七天周课表，支持全部周次、单双周、离散周次、同一时段多门课程。
- 自动尝试读取学期起始日期；手动编辑课程、教师、教室、节次与周次。
- 作业、考试和事件待办。
- 1–14 节作息配置、课前通知、今日课程桌面小组件。
- JSON 备份恢复、ICS 日历导出、三种主题色。

## 如何导入

1. 打开 App，点击“导入”，在校方页面自行登录。
2. 点底部“① 个人课表”，选择学期及“全部周次”。
3. 点“② 读取课表”，核对课程、星期、节次、周次和第一周的周一日期。
4. 首次导入或纠正旧课表请选择“替换课表”；需要保留已有课程时选择“追加课程”。
5. 保存后显示“全部周次”，便于与教务课表逐格对照；点击“本周”查看当周安排。

未取得可信学校作息时只显示节次和“待设置”，不会把通用参考时间当作学校钟点。可在设置里填写学校实际作息并勾选“已核对”。提醒和日历导出需要已确认的作息；提醒还需要开学日期和通知权限。

## 验证与当前状态

本版本已通过 Android 编译与签名验证、10 组核心逻辑检查、12 项解析与请求模拟检查，以及30项本地合成DOM/UI回归检查。

本地合成样例与浏览器模拟不能替代真实手机或学校认证后页面验证。当前适配仍需持续实测；接口或页面变化可能影响导入，请以教务系统原课表为准。通知采用系统非精确闹钟，可能受省电策略影响。

## 数据与隐私

课程和待办保存在本机，没有自建云同步服务。登录发生在校方网页中；App 不要求向开发者提供学校账号或密码。教务会话由 Android WebView 管理，可在设置中清除。

备份、日历和核对报告可能包含个人课程信息，分享前请自行检查。反馈问题请提供版本号、现象和去除个人信息后的示例，不要提交密码、Cookie或学号。

## 源码与构建

`src/` 包含 Java 原生壳、HTML/CSS/JavaScript 界面和本校教务解析器。`tests/` 包含可独立运行的合成测试；`downloads/` 提供已签名APK。

Windows 构建需要 Python 3、JDK 21、Android SDK Platform 35 与 Build Tools 35。先设置 `JAVA_HOME`，SDK默认目录结构如下，也可用 `QING_SDK` 指定另一根目录：

```text
tmp/sdk/android.jar
tmp/sdk/build-tools-35/aapt2.exe
tmp/sdk/build-tools-35/zipalign.exe
tmp/sdk/build-tools-35/lib/d8.jar
tmp/sdk/build-tools-35/lib/apksigner.jar
```

```powershell
python src/build.py
node tests/ui_tests.js
node tests/test-cupk-import.cjs
```

构建产物位于 `out/`。首次构建会生成自己的签名，保存在 `private/`；请妥善保存以便后续更新。仓库不包含发布签名私钥，自己生成的签名不能覆盖安装本仓库提供的已签名APK。
